# Plan: Real World Map with Precise Land Borders

## Goal
Replace the dot-per-country canvas map (`js/map.js`) with a real world map:
filled country polygons with precise land borders, colored per-country by
diplomatic relation, tap-to-select, pan/zoom — still 2D canvas, offline-first,
phone/tablet friendly, no build step.

## Approach (recommended)
Embed Natural Earth borders via `world-atlas@2.0.2` TopoJSON, decoded **once**
on the builder's machine and committed as a static `js/borders.js`
(`window.BORDERS`, keyed by the game's existing ISO alpha-2 codes). Rewrite
`js/map.js` to draw polygons; keep dots only as fallback for microstates that
have no polygon at 110m. Game logic (`game.js`, `countries.js`) untouched
except `focus()` centering a polygon bbox instead of a dot.

## Changes
1. **New `js/borders.js`** (one-time fetch + convert, file itself committed):
   - Source: `https://cdn.jsdelivr.net/npm/world-atlas@2.0.2/countries-110m.json`
     (+ `topojson-client` for the one-time decode, not shipped).
   - ISO numeric id → alpha-2 via `world-atlas@1.1.4/world/110m.tsv`
     (`826→GB`; drop non-game territories PR/GU/HK…; France/Somalia/Cyprus
     merged views kept as-is — matches the 193-UN game list; game has no
     XK/EH entries so nothing to special-case).
   - Keep only alpha-2 + polygons, round coords to 2 decimals, precompute per-iso
     bbox + largest-ring centroid; emit `window.BORDER_META` (source, missing list).
   - Target size ~80–150 KB. Fallback dots cover the ~40 microstates missing
     from 110m (SG, MC, MT, MV, Pacific islands…).
2. **`js/map.js` rewrite of draw/pick** (keep camera, projection, callbacks):
   - Fill each polygon with existing `relColor()`, stroke dark 1px borders;
     selection = white stroke, player = gold, war = red pulse.
   - Antimeridian (RU/FJ): offset-copy drawing at `x ± worldW`, no geometry edits.
   - Picking: screen→lon/lat → bbox prefilter → ray-cast point-in-polygon
     (small-bbox-first; 12px expanded touch target for tiny states).
   - Labels at precomputed centroids (majors at z>1.6 as today, more as you zoom).
   - Dirty-flag rendering (drop the every-frame rAF redraw) for phone battery.
3. **`index.html`**: add `<script src="js/borders.js">` after countries.js, before map.js.
4. **`sw.js`**: precache `js/borders.js`, bump cache `psim-v2→v3`, add old-cache cleanup.
5. **`js/game.js`**: `focus(iso)` centers polygon bbox (falls back to capital lat/lon
   for no-polygon states). Nothing else changes.

## Verification
- `ls -l js/borders.js` (<200 KB), no console errors.
- Local server + `playwright-cli`: desktop screenshot shows filled continents;
  mobile viewport 390×844: tap Brazil interior → Nation panel shows Brazil;
  select SG/MC → fallback dot works; pan past ±180° → RU/Fiji render cleanly.
- Ally green / enemy red / player gold fills; offline reload renders from SW cache;
  no long tasks while panning; idle = zero canvas work.
